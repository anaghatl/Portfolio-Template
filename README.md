# 🚀 Interactive Developer Portfolio Builder

A clean, responsive single-page web application that allows users to build and preview a customized developer portfolio in real time.

Built with pure HTML5, CSS3, and JavaScript, this tool lets developers and students input their professional details on the left and immediately see a styled resume/portfolio card render on the right, which can then be exported directly as a PDF.

## 🌟 Live Demo

Try the live application here: [Interactive Portfolio Builder](https://anaghatl.github.io/Portfolio-Template/)

## 🛠️ Key Features

- **Real-Time Live Preview**: As you type your name, bio, skills, project info, or contact details, the preview canvas updates dynamically.
- **Dynamic Skill Tags**: Turns comma-separated skills into clean visual tags automatically.
- **Print / PDF Export**: Features print-specific styling so users can export a clean, distraction-free PDF version of their generated portfolio card with one click.
- **Responsive Split Design**: Clean two-panel layout optimized for both desktop and mobile viewing.

## 🧰 Tech Stack

- **HTML5**: Semantic UI structure and form elements
- **CSS3**: Modern Grid & Flexbox layouts, dark dashboard interface, responsive styling, print stylesheets
- **JavaScript (ES6)**: Real-time event handling, DOM manipulation, and dynamic list rendering

## 🚀 How to Use / Run Locally

1. Clone or download this repository.
2. Open `index.html` directly in any web browser.
3. Fill out the form fields to customize your portfolio details.
4. Click **Print / Save as PDF** to generate your ready-to-use resume document!
